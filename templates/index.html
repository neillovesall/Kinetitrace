KINETRACE
The Recovery System Of The Future
KineTrace is a wearable micro-sensor mesh network designed for out-patient orthopedic rehabilitation. It addresses the critical data blackout between clinic visits by deploying a dual-node IMU framework on the thigh and shin segments, streaming 6-DOF kinematics via ESP-NOW at 50 Hz to a clinical dashboard in real time.

The system performs quaternion-space calibration, computes relative segment flexion angles via dot-product geometry, and scores movement quality against a gold-standard template using Numba-accelerated multidimensional Dynamic Time Warping. The Kinematic Adherence Score gives clinicians an objective, continuous compliance metric that no consumer wearable can provide.
